1. Introduction

What is Galecto?

Galecto is an enterprise observability platform that helps you monitor, debug, and optimize your applications.

🔍 Monitor

Track performance, errors, and health of your services in real-time.

🔧 Debug

Use replay functionality to quickly identify and fix issues.

🚀 Track

Correlate deployments with errors to understand what went wrong.

⏱️ Optimize

Set SLOs and continuously improve your service reliability.

5. Exploring Logs

Finding Logs

  1. Click "Logs" in the sidebar
  2. Use the search bar to find specific messages
  3. Apply filters to narrow results

Search Tips

  • By keyword: Type "error", "exception", "timeout"
  • By service: Filter to a specific service
  • By time: Select time range
  • By level: Filter by error, warning, info
💡 Tip: Click on any log entry to see full details including stack trace and request information.

7. Alert Management

Viewing Alerts

Click "Alerts" in the sidebar to see all alerts with status (Active, Acknowledged, Resolved).

Alert Severity Levels

  • 🔴 Critical - Immediate attention needed
  • 🟠 High - Important but not critical
  • 🟡 Medium - Should be addressed
  • 🟢 Low - Minor issues

Managing Alerts

Acknowledge: Click on the alert → Click "Acknowledge"

Resolve: Click on the acknowledged alert → Click "Resolve" → Add notes

8. Replay - Debug Failed Requests

What is Replay?

Replay lets you "replay" a failed request to see exactly what happened. This helps debug issues safely.

How to Use Replay

  1. Click "Replay" in the sidebar
  2. Search for the failed request (Trace ID, time range, service)
  3. Click on a failed request to view details
  4. Click "Replay" to execute a test
⚠️ Safety Features: Replay filters out sensitive headers, masks PII, and blocks dangerous URLs.

11. SLO Monitoring

What is SLO?

SLO (Service Level Objective) defines targets for service reliability, like "99.9% of requests should succeed."

Setting Up SLOs

  1. Click "SLOs" in the sidebar
  2. Click "+ New SLO"
  3. Configure: Name, Service, Type, Threshold, Window

SLO Status Indicators

  • ✅ Green - Meeting target
  • ⚠️ Yellow - At risk
  • ❌ Red - Breached

12. API Keys Management

Creating an API Key

  1. Go to Settings (gear icon)
  2. Click "API Keys"
  3. Click "+ Add API Key"
  4. Enter a name (e.g., "Production App")
  5. Select a role
  6. Click "Create"
  7. Copy the key - it won't be shown again!

Using Your API Key

curl -X POST http://localhost:3001/api/v1/ingest \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"service": "my-app", "name": "LOG", "payload": {"message": "Hello"}}

Rotating API Keys

  1. Create a new key
  2. Update your application to use the new key
  3. Revoke the old key

13. Notifications

Setting Up Notifications

Notification Types

  • Webhook - Enter webhook URL

14. Troubleshooting

Common Issues

Can't Log In?
- Check your email/password
- Clear browser cache
- Try incognito/private mode
Not Seeing Data?
- Verify API key is correct
- Check your application is sending data
- Ensure services are running
Alerts Not Receiving?
- Check notification settings
- Verify email/Slack configuration
- Check spam folder
